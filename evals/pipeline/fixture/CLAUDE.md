# sample-app

A small app the software factory builds tickets for.

**Linear team:** Acme

GitHub repository: `acme-labs/sample-app` (the `origin` remote).

## Layout

- `src/` holds the app's code, one file per change.
- `workflows/<date>-<ticket>-<slug>/` holds each ticket's spec, contract and test plan.
- The `verify` skill checks a change at the app's real surface.
